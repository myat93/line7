# Wooden guard camp

Separate exploration pocket. Linked off the service-tunnel far end — not part of `ruins/fallen_castle/`.

**Enter:** walk the tunnel past the locker. Sealed **CAMP** door on the far wall. **E** to travel.

**Loop (~45–60s, no fight)**

1. `palisade_enter` — gap in the palisade logs
2. `camp_tripod` — cook tripod orients the yard (landmark)
3. Check A — `lean_to_shelter` + torch post (look / walk-through)
4. Check B — `guard_plank` (short jump or roll from the step crate). Slow on the plank is an exposed silhouette; cones come later. Second lean-to (`STORE`) sits beside it.
5. Optional `camp_crate` — **E** stub loot (linen wrap / watch scrap). Skip = faster exit.
6. `mist_exit` — far gap, look-only fog wall / drop tease. No softlock.

Same path back. **E** at **TUNNEL** in the enter gap. Combat / shrine state is kept. No new enemy. No live guards.

Same HE controls: Shift sprint, Space jump, Ctrl roll.

Kit is cylinder logs and board planks (not grey cubes). No Kenney pack in-tree.

Debug: **0** toggles this pocket. **9** still toggles the tunnel. **8** still toggles the castle.
