# Line 7 tunnel pocket

Separate exploration path. Not part of `ruins/fallen_castle/`.

**Enter:** mid-platform, south of the Herald leash (`z > 8`). Sealed **SERVICE** door on the +X wall (`door_gap`). **E** to travel.

Leaving mid-fight means walking back through swipe range — soft punish, no softlock.

**Loop (same path back)**

1. `door_gap` — sealed service door / platform lip
2. `tunnel_flood` — tight flooded corridor, one jump gap (catch floor if you miss). Hanging pipe is flavor; roll does not crouch the capsule.
3. `tube_cluster` — flicker-tube navigation beacon
4. `relief_wall` — angel-stone in modern tile. Look only.
5. `maint_locker` — **E** stub loot: Ashpike hint note, or a dry wrap if the pike is already taken
6. Far-end **CAMP** door — **E** into `ruins/guard_camp/` (wooden palisade yard). Optional.

Return **E** at the **LINE 7** door. Combat / shrine state is kept. No new enemy.

Same HE controls: Shift sprint, Space jump, Ctrl roll.

Debug: **9** toggles this pocket from the undercroft. **8** still toggles the fallen castle. **0** toggles the guard camp.
