# Hollow Herald realistic mesh — licenses

`hollow_herald_realistic.glb` is **not** from Elden Ring or any commercial game rip.

## Humanoid body

- **Source:** Microsoft Rocketbox `Male_Adult_04` (zip jacket / street layers — coat bulk starting point)
- **Repo:** https://github.com/microsoft/Microsoft-Rocketbox
- **License:** MIT (Copyright (c) 2020 Microsoft) — see `LICENSE.rocketbox.md` in this folder
- **Modifications:** FBX → glTF/GLB, scaled to **2.05 m**, meters, Y-up, origin at the feet, Godot-forward (−Z). Body/head tinted ashen. Skeleton pose bones renamed to match `hollow_herald.gd` (`Hips`, `Torso`, `Head`, `R_UpperArm`, `L_UpperArm`, fists, thighs/shins).

## Transit coat + crown (Line 7 authored)

- Open transit-coat / raincoat flare, lapels, and a three-horn `Crown` mesh are original Line 7 geometry (not a game rip).
- PBR cloth/leather maps: [Poly Haven](https://polyhaven.com) `rough_linen` and `brown_leather` — **CC0 1.0**.

Swipe **2.4** / lunge **1.4** and the 1.15s / 1.25s wind-ups stay on the capsule. This file is visual-only.
